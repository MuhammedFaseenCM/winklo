**Goal:** Ship section A of `docs/superpowers/specs/2026-10-15-roadmap-batch-design.md` on `feat/rb-polish`: Zip replay of the best path, today's summary on Home, snoozing the soft update banner, Play in-app updates, prefetching tomorrow's puzzles, and App Links.

**Architecture:** Every feature lands in new files (cubits, widgets, repositories, use cases) with one-line hooks in the hotspot files (`home_screen.dart`, `app_router.dart`, `app_strings.dart`, `core/di/app_repositories.dart`, `zip_screen.dart`, the other two game screens). Domain stays pure Dart; Play, Firestore and shared_preferences sit behind repository interfaces registered from a new `core/di/update_and_prefetch_providers.dart`, spread into `buildRepositoryProviders`.

**Tech Stack:** Flutter 3.44 / Dart 3.12, flutter_bloc (Cubit), Flame (`ZipGame`), go_router 18, cloud_firestore, shared_preferences, new `in_app_update` ^5.0.0, `bloc_test` + `mocktail`.

/// Cells drawn per second while a review replays the saved path.
static const replayCellsPerSecond = 12.0;
List<Cell>? _replayCells;
double _replayElapsed = 0;
void Function()? _onReplayFinished;

bool get isReplaying => _replayCells != null;

/// Redraws [cells] from the first one, about [replayCellsPerSecond] a
/// second, then rests on the full path and calls [onReplayFinished] once.
/// Review only; ignored while a replay is running.
bool replay(List<Cell> cells, {void Function()? onReplayFinished}) {
  if (!readOnly || cells.isEmpty || isReplaying) return false;
  _replayCells = List<Cell>.unmodifiable(cells);
  _replayElapsed = 0;
  _onReplayFinished = onReplayFinished;
  path..clear()..add(cells.first);
  return true;
}
```

In `_drawPathStroke` use `_clampedLiveTip() ?? _replayTip()` where `_replayTip()` lerps from `path.last`'s centre towards the next cell by the fractional progress.

class ZipReplayState {
  const ZipReplayState({this.available = false, this.playing = false});
  final bool available;
  final bool playing;
  // == / hashCode on both fields
}

class ZipReplayCubit extends Cubit<ZipReplayState> {
  ZipReplayCubit({required ZipLevel level, required List<Cell> savedPath})
    : path = List.unmodifiable(savedPath),
      super(ZipReplayState(
        available: savedPath.isNotEmpty && PathValidator(level).isWon(savedPath),
      ));
  final List<Cell> path;
  bool start() { if (!state.available || state.playing) return false; emit(...playing: true); return true; }
  void finished() { if (isClosed || !state.playing) return; emit(...playing: false); }
}
```
